# 02: Poll 생성 검증

**What to build:** Creator가 잘못된 Poll을 만들 수 없게 한다. 앞뒤 공백을 제거한 뒤, 질문은 1–200자, Option은 1–100자이고 2–10개여야 하며, 대소문자를 무시해도 중복된 Option이 있으면 안 된다. 규칙을 어기면 해당 필드 옆에 무엇을 고쳐야 하는지 오류 메시지가 뜨고, 입력한 내용은 그대로 남는다. 폼에서 Option 입력칸을 추가·삭제할 수 있다(최소 2개, 최대 10개).

**Blocked by:** 01 (Poll 만들고 링크로 열기)

**Status:** ready-for-agent

- [ ] 검증은 Poll 도메인 모듈의 `createPoll` 안에 있고, 실패하면 필드별 오류를 담은 도메인 오류를 던진다
- [ ] 저장되는 질문과 Option은 앞뒤 공백이 제거되어 있다
- [ ] 빈 질문, 200자를 넘는 질문, 빈 Option, 100자를 넘는 Option, Option 1개 이하 또는 11개 이상, 대소문자만 다른 중복 Option은 거부된다
- [ ] 폼은 필드별 오류를 해당 필드 옆에 보여 주고, 입력한 값을 유지한다
- [ ] Option 입력칸 추가·삭제 버튼이 2–10개 범위를 지킨다
- [ ] 선택지를 모두 비워 직접 POST해도 Option 없는 Poll이 저장되지 않는다 (01에서 발견: 지금은 `required`가 브라우저에서만 막아서, 빈 Poll이 저장되고 링크가 404가 된다)
- [ ] 각 검증 규칙마다 Poll 모듈 테스트가 있다
