# 06: 공유와 마무리

**What to build:** Creator가 Poll 링크를 쉽게 공유하고, 메신저로 링크를 받은 사람이 휴대폰에서도 불편 없이 Vote할 수 있게 한다. 서버에서 문제가 생기면 다시 시도하라는 친절한 안내가 나온다.

**Blocked by:** 01 (Poll 만들고 링크로 열기)

**Status:** ready-for-agent

- [x] Poll 페이지에 "링크 복사" 버튼이 있고, 누르면 Poll URL이 클립보드에 복사되며 복사됐다는 표시가 나온다
- [x] 홈, Poll, not-found 화면(03이 끝났다면 Results 화면도)이 폭 360px 휴대폰 화면에서 가로 스크롤 없이 쓸 수 있다
- [x] 예상치 못한 서버 오류가 나면 한국어 안내와 다시 시도 버튼이 있는 오류 화면이 나온다
- [x] UI 문구는 한국어("투표", "선택지", "표")를 쓴다

## Comments

- 구현 완료. headless Chrome(360px, 모바일 에뮬레이션)으로 확인했다: 홈, Poll(긴 질문과 공백 없는 100자 Option), Results, not-found 모두 가로 스크롤이 없다. `<fieldset>`의 기본값 `min-width: min-content` 때문에 처음에는 867px로 넓어져서, fieldset에 `min-w-0`를 넣어 고쳤다.
- "링크 복사"는 `navigator.clipboard.writeText`가 성공하면 "복사했어요!"로 바뀐다. headless에서는 클립보드를 다시 읽을 수 없어 실제로 복사된 내용은 확인하지 못했다. 휴대폰에서 붙여넣어 확인이 필요하다. 클립보드를 쓸 수 없으면 주소를 화면에 보여 준다.
- 오류 화면: 프로덕션 빌드를 닿지 않는 DB로 띄워 Poll 페이지를 열면 "문제가 생겼어요"와 "다시 시도"가 나온다. DB가 꺼진 상태에서 Poll 만들기/Vote 제출(Server Action 오류)은 확인하지 않았다. 루트 레이아웃 오류용 `global-error.tsx`는 만들지 않았다(레이아웃에 데이터 조회가 없음).
- 같은 스크립트로 02의 JS 동작(선택지 추가·삭제, 거부 후 값 유지, 삭제 후 오래된 오류 숨김)도 확인했다.
