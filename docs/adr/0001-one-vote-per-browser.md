# 중복 투표는 브라우저 단위로만 막는다

로그인 없이 누구나 Poll을 만들고 Vote할 수 있게 하기 위해, Voter를 계정이 아니라 브라우저에 저장된 익명 ID(쿠키)로 식별하고 "Poll당 Voter당 Vote 1개"를 DB 제약으로 강제한다. 시크릿 창이나 다른 브라우저로 우회할 수 있다는 점은 알고 받아들였다. 가벼운 투표라는 목적에서 인증 기능을 만드는 비용이 더 크다고 판단했다.

## Considered Options

- 막지 않기: 새로고침만으로 결과를 조작할 수 있어 Results가 의미 없어진다.
- 로그인(계정 단위): 확실하지만 인증 기능이 필요하고, 참여 장벽이 "간단한 웹앱"이라는 목표와 맞지 않는다.

## Consequences

나중에 계정 단위로 바꾸려면 Vote의 Voter 식별 방식과 유일성 제약, 그리고 기존 Vote 데이터 이전이 모두 필요하다.
